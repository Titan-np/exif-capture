# EXIF Capture

Windows向けスクリーンショット撮影ツールです。  
Windows標準のキャプチャ機能では記録されない「撮影日時（EXIF / PNGメタデータ）」を画像内に自動保存することが可能です。

---

## 動作環境

- OS: Windows 10 / Windows 11 (64bit)
- Python: 3.11 以上（ソースコードから実行・ビルドする場合）

## 使い方

起動するとタスクバーに常駐し、以下を行うことができます。

### スクリーンショットの撮影

- ショートカットキー (デフォルトでは `Shift + PrintScreen` ) を押すことで、現在アクティブなウィンドウを撮影・保存します。
- 撮影後に表示されるWindows通知のボタンから、撮影した画像や保存先フォルダを開くことができます。
- 撮影日時（EXIF / PNGメタデータ）の埋め込みに対応しています。

### タスクバー（通知領域）メニュー

- ダブルクリック: 設定画面を表示します。
- 右クリックメニュー:
  - 設定を開く: 設定画面を表示します。
  - 保存先フォルダを開く: スクリーンショットの保存先フォルダをエクスプローラーで開きます。
  - ログファイルを開く: アプリケーションの動作ログファイルを既定のテキストエディタで開きます。
  - 終了: アプリケーションを終了します。

### 設定画面

設定画面から以下の項目をカスタマイズできます。

| 設定項目             | 説明                                              | 初期値                    |
| -------------------- | ------------------------------------------------- | ------------------------- |
| ショートカットキー   | 撮影を実行するキーの組み合わせ                    | Shift + PrintScreen       |
| 撮影時の通知音量     | 撮影時に再生するシャッター音の音量（0でミュート） | 100%                      |
| 保存先フォルダ       | スクリーンショット画像を保存するフォルダパス      | C:\Screenshots            |
| ファイル名プリセット | 保存するファイル名の命名規則（拡張子含む）        | `{timestamp}_{title}.png` |
| 撮影日時の記録       | 画像内にEXIF/メタデータを埋め込むかどうか         | オン                      |
| システム通知         | Windows通知を表示するかどうか                     | オン                      |

## 導入・実行手順

### 配布パッケージ（exe）を利用する場合

1. Releases等から最新版の実行ファイル（`EXIF Capture.exe`）をダウンロードします。
2. 任意のフォルダに配置し、実行します。
3. タスクバーの通知領域にアイコンが表示され、常駐が開始されます。

### ソースコードから実行・ビルドする場合

1. リポジトリをクローンまたはダウンロードします。
2. 必要なパッケージをインストールします。

```bash
pip install -r requirements.txt
```

3. アプリケーションを起動します。

```bash
python src/main.pyw
```

4. 実行ファイル（exe）をビルドする場合は、付属のビルドツールを実行します。

```bash
python tools/build.py
```

ビルドが完了すると `dist/` フォルダ内に `EXIF Capture.exe` が生成されます。
