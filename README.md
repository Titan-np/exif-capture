# [EXIF Capture](https://github.com/Titan-np/exif-capture)

Windows向けスクリーンショット撮影ツールです。  
Windows標準のキャプチャ機能では記録されない「撮影日時（EXIF / PNGメタデータ）」を画像内に自動保存することが可能です。

---

## 動作環境

- OS: Windows 10 / Windows 11 (64bit)
- Python: 3.11 以上（ソースコードから実行・ビルドする場合）

## 使い方

起動するとタスクバーに常駐し、以下を行うことができます。

### スクリーンショットの撮影

- ショートカットキー (デフォルトでは `Shift + PrintScreen` ) を押すことで、現在アクティブなウィンドウを撮影・保存します。
- 撮影後に表示されるWindows通知のボタンから、撮影した画像や保存先フォルダを開くことができます。
- 撮影日時（EXIF / PNGメタデータ）の埋め込みに対応しています。

### タスクバー（通知領域）メニュー

- ダブルクリック: 設定画面を表示します。
- 右クリックメニュー:
  - 設定を開く: 設定画面を表示します。
  - 保存先フォルダを開く: スクリーンショットの保存先フォルダをエクスプローラーで開きます。
  - ログファイルを開く: アプリケーションの動作ログファイルを既定のテキストエディタで開きます。ログファイルが1MBを超えると、次回起動時に app.log.old へ退避し、2世代まで保持します。
  - 終了: アプリケーションを終了します。

### 設定画面

設定画面から以下の項目をカスタマイズできます。

| タブ         | 設定項目                | 説明                                                         | 初期値                         |
| ------------ | ----------------------- | ------------------------------------------------------------ | ------------------------------ |
| 撮影         | ショートカットキー      | 撮影を実行するキーの組み合わせ                               | `Shift + PrintScreen`          |
| 撮影         | 撮影時の通知音量        | 撮影時に再生するシャッター音の音量（0でミュート）            | 100%                           |
| 保存         | 保存先フォルダ          | スクリーンショット画像を保存するフォルダパス                 | `~/Pictures/Screenshots`       |
| 保存         | ファイル名プリセット    | 保存するファイル名の命名規則（拡張子含む）                   | `{timestamp}_{title}{dup}.png` |
| 保存         | 撮影日時の記録          | 画像内にEXIF/メタデータを埋め込むかどうか                    | オン                           |
| Windows機能  | Windows起動時の自動起動 | スタートアップへの登録・解除（ボタンを押した時点で反映）     | 未登録                         |
| Windows機能  | 撮影時の通知            | 撮影時にWindows通知を表示するかどうか                        | オン                           |
| Windows機能  | 起動・終了時などの通知  | 起動・終了時やショートカットキー変更時に通知するかどうか     | オン                           |
| Windows機能  | エラー発生時の通知      | 撮影の失敗などのエラー発生時に通知するかどうか               | オン                           |
| アップデート | アップデートの確認      | 起動時に新しいバージョンを確認・通知する範囲                 | 正式版のみ確認する             |
| アップデート | 今すぐ確認              | 新しいバージョンをその場で確認し、結果を設定画面内に表示する | -                              |

ファイル名プリセットでは、以下のプレースホルダを使用できます。

| プレースホルダ | 内容                                               | 書式指定の例                                                                 |
| -------------- | -------------------------------------------------- | ---------------------------------------------------------------------------- |
| `{timestamp}`  | 撮影日時（書式指定なしは `%Y%m%d_%H%M%S`）         | `{timestamp:%Y%m%d}`、`{timestamp:%H%M%S_%f}`（`%f` はマイクロ秒6桁）        |
| `{title}`      | ウィンドウタイトル                                 | -                                                                            |
| `{index}`      | 保存先フォルダ内で被らない連番（1から）            | `{index:03}` → `001`                                                         |
| `{dup}`        | 同名ファイルがある時のみ付く連番（書式指定なしは ` (2)`） | `{dup:_%d}` → `_2`、`{dup:_%02d}` → `_02`、`{dup:_%d:1}` → 2件目から `_1` |

`{index}`・`{dup}`・`%f` 付きの `{timestamp}` のいずれも含まないプリセットは、同名のファイルを上書きする恐れがあるため設定画面で警告を表示します。

## 導入・実行手順

### 配布パッケージ（exe）を利用する場合

1. Releases等から最新版の実行ファイルが格納された圧縮ファイル（`EXIF_Capture_v◯.◯.◯.zip`）をダウンロードします。
2. 任意のフォルダに解凍し、実行します。
3. タスクバーの通知領域にアイコンが表示され、常駐が開始されます。

### 配布パッケージ（exe）をアップデートする場合

1. 最新版の圧縮ファイルをダウンロードして解凍し、既存の `EXIF Capture.exe` に上書きします。

設定ファイル（`settings.json`）は実行ファイルと同じフォルダに保存されているため、上書き後も設定は引き継がれます。
スタートアップに登録済みの場合、実行ファイルを別のフォルダへ移しても、次回の起動時に登録先が更新されます。

### ソースコードから実行・ビルドする場合

1. リポジトリをクローンまたはダウンロードします。
2. 必要なパッケージをインストールします。

```bash
pip install -r requirements.txt
```

3. アプリケーションを起動します。

```bash
python src/main.pyw
```

4. 実行ファイル（exe）をビルドする場合は、付属のビルドツールを実行します。

```bash
python tools/build.py
```

ビルドが完了すると `dist/` フォルダ内に `EXIF Capture.exe` が生成されます。
